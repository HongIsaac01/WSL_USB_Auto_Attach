# WSL USB Manager

WSL에서 USB 장치를 쉽게 Attach/Detach하고,
선택한 장치를 자동으로 Attach할 수 있도록 도와주는
Visual Studio Code Extension입니다.

## Features

- USB device list
- Attach USB device to WSL
- Detach USB device from WSL
- Auto Attach by VID:PID
- Device alias support
- TreeView based device management

## Requirements

- Windows
- WSL
- usbipd-win
- Visual Studio Code Remote - WSL

## Usage

1. Open VS Code in WSL.
2. Open the `WSL USB` view from the Activity Bar.
3. Attach or detach USB devices.
4. Enable Auto Attach for devices you want automatically connected.
